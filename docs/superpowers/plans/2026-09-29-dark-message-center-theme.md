# 深色消息中心主题实施计划

> **For agentic workers:** 本计划已在当前会话内按快速模式执行，未改变业务接口或页面路由。

**Goal:** 以 `docs/ui-mockups/2026-09-29-workbench-v4.html` 为视觉真源，将统一消息中心的顶部导航和桌面端联系人会话侧栏改为深色 chrome，并让右侧联系人工作区使用浅灰画布承托白色圆角工作台；业务行为保持不变。

**Architecture:** 通过 `messageCenterTheme.css` 提供局部样式作用域；`AppLayout` 增加语义类名并提供浅灰内容画布，`ThreadPage` 划分白色圆角工作台、时间轴底板和发送区，`ContactsPage` 和 `ContactCard` 只增加行状态类名并移除冲突的浅色内联颜色。联系人头像使用联系人 ID 的稳定哈希选择视觉真源中的色板，渠道类型映射为头像角标；搜索、权限菜单、排序、右键操作和移动端抽屉继续复用现有实现。

**Tech Stack:** React 18, TypeScript, Ant Design 5, Vitest, Vite。

## 验收范围

- 顶部导航使用深色背景、浅色文字和深色 hover/focus 状态。
- 顶部下拉入口打开时使用浅灰选中胶囊、圆角和轻阴影，保持当前菜单项的视觉焦点。
- 桌面端联系人侧栏、搜索框、会话列表、选中态、群聊态和底部计数使用深色配色。
- 会话分区展示真实的会话总数、未读总数和当前结果中的渠道数量；不伪造“待回复”或全局渠道统计。
- 联系人行使用首字符头像、稳定颜色和最多两个渠道角标，未读继续使用服务端 `unreadCount`。
- 没有最后一条消息时保持预览区域为空，不显示占位文案；会话块之间保留间距和圆角留白。
- 联系人主内容区域使用 `#f1f2f4` 浅灰画布，时间轴和发送区保留独立圆角、间距与底板层次。
- 不新增接口、不修改路由、不改变联系人列表业务语义。
- 运行 AppLayout、ContactCard、ContactsPage 定向测试和前端生产构建。
