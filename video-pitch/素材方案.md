## 二、可复现的命令

**换配音音色**（本机有 9 套中文语音）：

```bash
# 看全部中文语音
say -v '?' | grep zh_CN
# 重出（-r = 字/分钟；Tingting 女声，Sandy/Shelley 偏播音，Eddy/Reed/Rocko 男声）
say -v Sandy -r 200 -o /tmp/x.aiff "文案"
ffmpeg -y -i /tmp/x.aiff -codec:a libmp3lame -b:a 128k out.mp3
```

**补图标**（模板变量换成 slug 即可）：

```bash
curl -sL "https://unpkg.com/simple-icons@latest/icons/<slug>.svg" -o brand/<slug>.svg
curl -sL "https://unpkg.com/lucide-static@latest/icons/<name>.svg" -o ui/<name>.svg
```

**重出 BGM**：改 `/tmp/gen_bgm.py` 里的频率组与 LFO，跑

```bash
/Users/z/.workbuddy/binaries/python/envs/default/bin/python /tmp/gen_bgm.py /tmp/bgm.wav
ffmpeg -y -i /tmp/bgm.wav -codec:a libmp3lame -b:a 160k bgm.mp3
```

## 五、字体（一个真实风险）

`src/theme.ts` 现在用的是：

```
system-ui, -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif
```

本机有 PingFang，所以现在渲染正常。但**换机器渲染就会 fallback，排版会漂**（中文断行、字重、字宽全变）。

要锁死的话，把字体文件打进项目：

```bash
cd video-pitch
PATH="/opt/homebrew/bin:/usr/bin:/bin" /opt/homebrew/bin/npm install \
  @fontsource/noto-sans-sc --registry=https://registry.npmmirror.com
```

然后在 `theme.ts` 里把 `font.sans` 指向本地字体族，并在 Remotion 的 `index.ts` 里 import 对应 CSS。

> 备注：`@fontsource/noto-sans-sc` 在 npmmirror 上可达（实测 200），但中文包体积较大（几十 MB）。如果只在你这台机器出片，**可以先不做**。
